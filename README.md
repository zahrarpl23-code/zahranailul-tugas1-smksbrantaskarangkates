# Profil Pribadi Zahra Nailul Aisyah

Website profil pribadi sederhana yang dibuat menggunakan HTML dan CSS.

## Tentang Proyek
Website ini menampilkan informasi pribadi, keterampilan yang sedang dipelajari, tujuan karier, hobi, dan kontak email.

## Fitur
- Kartu profil dengan tema dark navy
- Judul berwarna ungu
- Informasi tentang diri
- Daftar skill yang sedang dipelajari
- Goals dan hobi
- Informasi kontak email

## Teknologi
- HTML5
- CSS3

## Cara Menjalankan
1. Clone atau download repository ini.
2. Buka folder proyek di Visual Studio Code.
3. Buka file index.html menggunakan browser atau Live Server.
